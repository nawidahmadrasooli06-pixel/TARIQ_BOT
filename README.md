- Documents
- Personal profile

- Channel button

- GitHub deployment

## Environment Variables

The following environment variables are required:

BOT_TOKEN
ADMIN_USERNAME
ADMIN_CHAT_ID

BOT_TOKEN must never be published publicly.

## Deployment

This project is designed to run on Render as a Web Service.

Start command:

python bot.py
